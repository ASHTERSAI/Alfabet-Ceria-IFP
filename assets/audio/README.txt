PANDUAN AUDIO OFFLINE UNTUK APK & GITHUB PAGES
==============================================
Folder ini disiapkan jika Ibu/Bapak Guru ingin membundel rekaman suara asli sendiri
ke dalam APK Android atau repositori GitHub Pages agar 100% offline.

Cara pakai:
1. Rekam suara lewat menu "Pengaturan & Suara Guru" di dalam aplikasi lalu unduh,
   ATAU siapkan file audio format .mp3 / .wav dari HP/laptop.
2. Beri nama file huruf kecil sesuai abjad:
   a.mp3, b.mp3, c.mp3, ... sampai z.mp3
3. Taruh file tersebut di dalam folder "assets/audio/" ini.
4. Aplikasi otomatis memprioritaskan rekaman guru dan file di folder ini sebelum memakai
   suara sistem / online.
